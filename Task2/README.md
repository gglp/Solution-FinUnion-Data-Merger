# Архитектура данных FinUnion Group после объединения с RetailBank: мастер-системы и потоки данных

Комплект документов определяет мастер-системы ключевых сущностей, правила владения данными, потоки данных промежуточного состояния (3 месяца), правила управления потоками и проблемные зависимости. Опирается на результаты анализа данных, сущностей и хранилищ: состав из 15 ключевых сущностей, логическую модель, классификацию данных и маппинг BIAN.

## Ключевые решения

| № | Решение | Обоснование |
| --- | --- | --- |
| 1 | MDM Customer Hub — мастер только для клиента, кросс-ссылок, связей клиентов и справочников | Счета, договоры, карты, кредиты, операции и платежи — учётные данные; их мастер — профильные банковские системы по границам сервисных доменов BIAN |
| 2 | Через 3 месяца MDM работает в реестровой модели, через 12 — в модели сосуществования | Единый идентификатор и золотая запись появляются без изменения процессов онбординга в CRM и без остановки обслуживания |
| 3 | В переходный период мастер договоров, счетов и операций определяется по организации, где открыт продукт | Системы RB нельзя заменить за один шаг; новые продукты FinUnion для клиентов RB открываются в системах FU |
| 4 | Данные RB попадают в аналитику через CDC и Integration Layer, а не прямыми выгрузками | Снижение нагрузки на RB Core, единая точка контроля качества и lineage |
| 5 | Регуляторная отчётность RB остаётся в RB DWH до реорганизации, единая отчётность строится как управленческая | Не менять регламентный контур в первые 3 месяца; расхождения контролируются ежедневной сверкой |
| 6 | Признак согласия на обработку ПДн ведётся в MDM и проверяется в потоках к системам FU | Законность передачи данных клиентов RB в FinUnion |

## Допущения

| № | Допущение | Влияние при невыполнении |
| --- | --- | --- |
| 1 | RetailBank в первые 3 месяца остаётся отдельным юридическим лицом и сдаёт регуляторную отчётность самостоятельно | При более ранней реорганизации перенос регуляторной отчётности RB в DWH становится задачей промежуточного состояния |
| 2 | Базы RB Core и RB CRM поддерживают чтение журнала изменений для CDC | Потребуются пакетные выгрузки с более высокой нагрузкой и задержкой |
| 3 | FU DWH имеет запас мощности для данных RB | Потребуется ускоренное развёртывание целевого DWH |
